## Common pass/fail gate

- Start a fresh separate task for each pack with only the indicated source attachments. Never attach this key, directions.md, the whole ZIP, or another pack's inputs/results.
- Preserve sources unchanged. No internal work search, web, connectors, send, share, permission changes, or actual commitments. Prompt scope is not a security boundary; use supported application controls and organizational policy. If isolation cannot be assured, do not run live.
- Each requested editable output exists, opens, and is prominently labeled fictional, draft, and human-review required. A chat response alone does not pass a requested-file checkpoint.
- Citations resolve to actual bare source filenames and sections or original Excel rows; invented citations fail. Workbook formulas, not just displayed totals, must be inspectable and recalculate without errors.
- Narrative and workbook agree. Unsupported claims remain qualified; a missing document is not proof of noncompliance. An evidence state is not an overall compliance or certification verdict.
- Inspect privately before sharing only the relevant application window; suppress notifications and hide unrelated work. Mark rehearsal backups PREPARED REHEARSAL OUTPUT — NOT LIVE, or PRERECORDED DEMONSTRATION — NOT LIVE.
- No external sharing occurs as part of these instructions. If files are later approved for customers, use local downloadable copies and permitted external sharing. Do not promise customer access to Microsoft tenant links.
